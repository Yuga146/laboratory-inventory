# Laboratory Test Catalogue

A searchable laboratory test catalogue and inventory management website based on the **Premier Integrated Labs – Price & Service Catalogue V3.01**.

## Features

- Search laboratory tests by name, code, or package contents
- View test prices in Malaysian Ringgit (RM)
- Display specimen types and collection quantities where available
- View fasting and sample collection instructions where documented
- Expand screening packages to see their included tests
- Filter tests by category
- Add new laboratory tests manually
- Import and export manually added tests in JSON format
- Luxury light and dark themes
- Responsive layout for desktop, laptop, tablet, and mobile
- Vertical scrollbar and pagination
- Pantai laboratory contact information for tests requiring confirmation

## Project Files

| File | Description |
|---|---|
| `index.html` | Website layout, styling, and interface |
| `catalogue-data.js` | Laboratory test names, codes, prices, and available test details |
| `app.js` | Search, filters, themes, pagination, and inventory functions |

## How to Use

1. Open the live website.
2. Search for a laboratory test by name or code.
3. Select a category to filter the results.
4. Click **View More** to see the included tests in a package.
5. Review the available specimen requirements, pricing, and fasting instructions.
6. Use **Add New Test** to enter additional laboratory tests.

## Data Accuracy

The catalogue is being populated from the 138-page Premier Integrated Labs Price & Service Catalogue V3.01.

The current starter version contains 12 extracted test records. Additional records will be added after extraction and verification.

Some specimen requirements, fasting instructions, prices, and package contents may be incomplete or require confirmation.

**Always verify laboratory requirements and current prices with the laboratory before clinical or operational use.**

## Important Notes

- The website is hosted using GitHub Pages.
- No backend database is currently connected.
- Manually added tests are stored locally in the user's browser when browser storage is available.
- Changes made through Add New Test do not automatically update the GitHub repository.
- Do not enter patient-identifiable or confidential information.
